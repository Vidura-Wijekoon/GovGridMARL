# `data/`

Datasets are **not** committed (see `.gitignore`). This folder documents how
to obtain them and stores access logs.

| Subfolder | Contents |
|---|---|
| `raw/` | Original downloads (REDD, UK-DALE), unmodified |
| `interim/` | Partially processed / cleaned data |
| `processed/` | Model-ready load profiles mapped to IEEE-14 buses |

## Sources (task m2-t9)

- **REDD** — Reference Energy Disaggregation Data Set (MIT). Request access via
  the dataset's official site; record the date and licence in `ACCESS_LOG.md`.
- **UK-DALE** — UK Domestic Appliance-Level Electricity. Available from the
  UK Energy Research Centre data centre.

Synthetic profiles (task m2-t10) are generated by
`govgridmarl.data.synthetic.generate_profiles` and are reproducible from a seed.
